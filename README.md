# AEGIS Capture macOS

SwiftUI app that selects a region over MT5 chart, captures screenshots, and sends to AEGIS cloud for signals.

## Build .app
1. Open `AegisCapture-Mac` folder in Xcode
2. Select "Any Mac" as target
3. Product -> Archive -> Distribute App -> Developer ID -> Export
4. Result: `AEGIS Capture.app`

## First Run
MacOS will ask "Screen Recording Permission". Go to System Settings -> Privacy & Security -> Screen Recording and enable AEGIS Capture.
